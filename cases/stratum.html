Stratum — GPA design system

Design system for the GPA toolset

This page is a placeholder. The full case study is in progress.

Stratum is the design system I built for GPA. The whole interface stands on a grid and design tokens: sizes, colors, layers, components and icons.

It has two themes: a light one in Intel’s brand colors and a dark one for game developers used to pro tools.
